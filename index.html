Rein it in with a card

1
Open the Cheat Sheet and copy the Edit level card.
2
Paste it into your chat, followed by this:
[paste the card here] Proofread only this paragraph and show the changes before finalizing: [paste the paragraph]
3
Check the marked-up changes and approve the ones you want. Nothing else gets touched.
Still drifting? Start the chat with the Manuscript Editing mode instead.

Set the ground rules with a mode

1
Open Modes. Copy Prompt Mode and Task Focus, then Manuscript Editing, and paste both into a new chat.
2
Let the AI write the full prompt for you:
Prompts Only: Proofread the attached chapter and suggest clearer wording for any awkward sentences. The author wants Australian English. Don't change anything else.
3
Read the prompt it gives back. Ask for changes if something is missing.
4
Type Go to run it.
The modes stay in force for the whole chat. Paste them again if a long chat starts to wander.

Build your first skill: Proofread Pass

Walk through it one step at a time. It takes about ten minutes.

Step 1 of 6: Ask the AI to build it

Open a new chat and paste this request:

Build me a skill called Proofread Pass. When I give you a passage, proofread it for spelling, grammar, and punctuation in American English unless I name another variety (UK, Canadian, Australian). Suggest clearer wording for sentences that are hard to follow, without changing the meaning or the author's voice. Change nothing else. Return the passage marked up with deletions struck through and additions in bold, then a short numbered list of the changes. After I approve, return the clean final text with only the approved changes. Then walk me through installing it.

Step 2 of 6: Check the draft

The AI writes the skill and shows it to you. Before you accept it, make sure it says:

  • use American English unless you name another
  • change nothing beyond what you ask
  • show a marked-up version before finalizing

If anything is missing, say so, for example: "Add a rule to leave quotations in their original spelling."

Step 3 of 6: Install it

Follow the install steps the AI gives you. Claude and ChatGPT both keep skills in their settings, but the menus change often, so let the AI give you the current steps.

Step 4 of 6: Test it on one page

Try it on something short:

Run Proofread Pass on this paragraph:

Paste a paragraph after it. Check that the changes come marked up, nothing else changed, and nothing is final until you approve.

Step 5 of 6: Fine-tune it

Tell the AI what to adjust, and it updates the skill:

Update the Proofread Pass skill to leave dialogue punctuation alone.

Step 6 of 6: Use it every week

From now on a short request is enough, with no pasting:

Proofread Pass on this page.

To add it to your Skills page, use the Skills Page Maintainer sample as a guide.
